# REDWAVE — Telegram Mini App

Мобильное музыкальное мини-приложение в красно-чёрном неоновом стиле. Работает как статический сайт, без сборки и платного сервера.

## Важно про музыку
В этой версии каталог ищется через публичный Apple iTunes Search API, а встроенный `<audio>` проигрывает `previewUrl`, если он доступен (обычно это короткий ознакомительный фрагмент). Это **не** даёт полный доступ к песням. Полные треки можно воспроизводить только через провайдера, чьи условия и API прямо разрешают такое использование, либо из аудио, на которое у вас есть права. Доступность API/превью может меняться; некоторые превью могут не запускаться в отдельных регионах или браузерах.

## Функции
- поиск по каталогу iTunes Search API;
- проигрывание доступных превью прямо в Mini App;
- очередь, следующий трек, перемотка;
- избранное и локальное сохранение;
- создание плейлистов (хранятся в браузере пользователя);
- адаптивный интерфейс, навигация, Telegram WebApp SDK.

## Быстрый локальный запуск
Откройте `index.html` в браузере. Некоторые браузеры ограничивают запросы API для `file://`, поэтому надёжнее запустить простой сервер:
1. Установите Python 3.
2. В папке проекта выполните `python -m http.server 8080`.
3. Откройте `http://localhost:8080`.

## Бесплатная публикация через Cloudflare Pages
1. Распакуйте архив.
2. Создайте репозиторий на GitHub и загрузите **содержимое** папки проекта (`index.html`, `style.css`, `app.js`, `README.md`).
3. В Cloudflare откройте Workers & Pages → Create → Pages → Connect to Git.
4. Выберите репозиторий. Для обычного статического сайта оставьте Build command пустой, Build output directory — `/` (корень репозитория), затем Deploy.
5. После публикации получите HTTPS-адрес вида `https://имя-проекта.pages.dev`.

Можно воспользоваться Direct Upload, если в вашей панели доступен этот вариант: загрузите папку/архив по подсказкам Cloudflare Pages.

## Подключение к Telegram
1. Откройте `@BotFather` в Telegram и выполните `/newbot`. Задайте имя и username. Сохраните токен приватно; **не отправляйте его в чаты и не вставляйте в код фронтенда**.
2. В BotFather откройте `/mybots` → выберите бота → Bot Settings → Configure Mini App (названия пунктов могут немного отличаться) и укажите опубликованный HTTPS URL. Если доступна настройка Main App, задайте тот же URL.
3. Для кнопки меню бота можно открыть настройки `/mybots` → Bot Settings → Menu Button и установить URL Mini App. Либо используйте настройку Mini App, предложенную BotFather.
4. Нажмите кнопку запуска приложения в профиле бота. Для проверки используйте опубликованный HTTPS URL, а не `localhost`.

## Ограничения первой версии
- Избранное и плейлисты хранятся в `localStorage` этого браузера/вебвью; они не синхронизируются между устройствами и могут потеряться при очистке данных.
- Настоящие персональные рекомендации пока простые: каталог по запросу; серверной аналитики и аккаунтов нет.
- Создание плейлиста работает локально; в интерфейсе можно создавать списки, но полноценное добавление произвольного набора треков в выбранный плейлист стоит развить следующим шагом.
- Для синхронизации пользователей, хранения плейлистов в облаке и защиты ключей потребуется backend (например, Cloudflare Workers + D1) и Telegram `initData` на сервере.
- Не вставляйте секретные API-ключи в `app.js`: код сайта доступен всем пользователям.
